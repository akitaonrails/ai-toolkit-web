# Languages

The site is English only for now, by the owner's decision (2026-09-23): translations wait until he has reviewed and approved the English text.

The machinery from the sister sites is in place, so adding Brazilian Portuguese later is mechanical:

- Every visible string lives in `src/i18n/locales/en/<namespace>.json`. Pages read them with `useI18n(Astro, '<namespace>')`, `t()`, `raw()` and join structure to words with `withText()`. Internal links go through `href()`.
- `src/i18n/languages.json` lists the languages. With one entry, the language menu, `hreflang` tags and first-visit redirect are all switched off automatically.

To add Portuguese when approved:

1. Add the `pt-br` entry back to `src/i18n/languages.json` (copy it from `~/Projects/ai-jail-web/src/i18n/languages.json`).
2. Copy `src/i18n/locales/en/` to `src/i18n/locales/pt-br/` and translate. Blog links should then point at the Portuguese posts (drop `/en` from the paths in `src/data/articles.ts` for that locale).
3. Localize diagram labels with `scripts/localize-image.mjs` (needs an `images.json` namespace, see the sister sites).
4. `npm run i18n:stamp`, then `npm run check:i18n`.
